# ProxyPulse v1.1.0

菜单栏上的代理链路监控：不再靠猜，直接告诉你「断了没有、卡在哪一段」。

## 这一版的核心变化

**双路对照探测。** 之前只会问「通不通」，现在同时打两条路：

- 海外探测走你的代理，验证隧道是否真的在搬运数据
- 国内探测做对照，如果国内通、海外不通，说明是节点或分流规则的问题，而不是你家网络断了
- 外加直连路由器，如果路由器都不响应，那就是本地网络本身的问题

三种信息组合起来，面板会给出一个明确结论，而不是一个含糊的红绿灯。

## 新增

- **双路延迟对比**：海外与国内延迟并排显示，判断是节点慢还是家宽慢
- **局域网探测**：断网时分清责任方
- **通用二进制**：Apple 芯片与 Intel 都能跑（`arm64 + x86_64`）
- **一键测速**：跑一次真实下载，给出 Mbps 与实际平均 MB/s
- **累计中断统计**：断线次数 + 累计中断时长，配合事件记录回溯「到底卡了多久」
- 命令行调试入口：`--dump`、`--snapshot`、`--speedtest`，不用开界面就能看数据

## 改进

- **断线判定从约 10 秒缩短到约 5 秒**：探测改为链式调度（上一次结束再排下一次），超时不再拖累检测节奏
- **冷启动不再误报**：首个探测常因建连/解析偏慢失败，现在直接丢弃，不会在启动瞬间闪一次「网络不稳」
- **延迟曲线重做**：每次探测一根柱条，失败的那次标红点，一眼看出什么时候抖过
- **图表面板自适应**：时间轴固定 90 格右对齐，数据少时不会把两个点拉满整屏；面板高度按内容收缩

## 修复

- 探测失败时不记录握手耗时，导致无法区分「端口活着但隧道死了」和「端口都没了」
- 单次探测失败即报「网络抖动」，判断过于敏感

## 安装

1. 下载 `ProxyPulse.dmg`，把 app 拖进「应用程序」
2. 首次打开会被 Gatekeeper 拦下（本项目没有 Apple 开发者签名），执行一次：

```bash
xattr -dr com.apple.quarantine /Applications/ProxyPulse.app
```

也可以先双击一次，然后去 **系统设置 → 隐私与安全性 → 仍要打开**。

要求 macOS 13 或更高。

## 已知限制

- 统计的是物理网卡总流量，包含所有 App 的流量
- 只读取系统 HTTP 代理；SOCKS5-only 配置下延迟读数可能不准
- 探测目标固定为 Google 与百度的端点
