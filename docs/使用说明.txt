ProxyPulse 1.1  —  macOS 菜单栏代理链路监控
================================================

做什么
------
常驻菜单栏，实时显示：
  · 当前上下行速率（菜单栏直接看）
  · 连接状态：正常 / 不稳 / 隧道不通 / 本地网络断开 / 代理未响应 / 未开启
  · 海外与国内延迟对比、丢包率、抖动
  · 每次断线的时间点和持续时长（事件记录）

判定方式不是「有没有流量」，而是每 2 秒真发一次请求：
海外探测走代理（验证隧道）、国内探测做对照（区分节点问题还是家宽问题）、
直连路由器（验证局域网）。所以挂着不动也能判断通不通。


安装
----
1. 把 ProxyPulse.app 拖到左边的「Applications / 应用程序」文件夹
2. 在「应用程序」里双击打开
3. 菜单栏右上角出现一个彩色小圆点 + 速率数字，点它看详情


首次打开被系统拦下怎么办
------------------------
这个包没有 Apple 开发者签名（那需要每年 99 美元的开发者账号），
所以从网上下载、或用微信/AirDrop 传过来后，macOS 会提示
「无法打开，因为无法验证开发者」或「Apple 无法验证此 App 是否包含恶意软件」。
两种办法任选其一：

方法 A（最稳，所有 macOS 版本通用）
  打开「终端」，粘贴执行：
      xattr -dr com.apple.quarantine /Applications/ProxyPulse.app
  然后再双击打开。

方法 B（图形界面）
  macOS 26 / 15：先双击一次，被拦下后去
      系统设置 → 隐私与安全性 → 底部「安全性」区域 → 点「仍要打开」→ 输入密码
  macOS 14 及更早：在「应用程序」里按住 Control 键点 ProxyPulse.app，
      选「打开」，弹窗里再点一次「打开」。

提示：如果拷过去后连图标都没有（显示为禁止符号），说明文件被系统隔离了，
      用方法 A 处理后即可。


使用
----
· 点菜单栏图标开面板，点别处自动收起
· 「测速」按钮：跑一次真实下载，看当前链路能跑多快
· 「重置统计」：清零累计流量、断线次数和事件记录
· 「退出」结束程序
· 想开机自启：系统设置 → 通用 → 登录项 → 添加 ProxyPulse.app


说明
----
· 支持 Apple 芯片和 Intel 芯片，需要 macOS 13 或更高
· 不联网上传任何数据，全部在本机计算；请求只发往固定的探测地址
  （connectivitycheck.gstatic.com、www.baidu.com、你的代理端口）
· 代理信息自动从系统设置读取，不用手动配置端口
  若只在代理软件里开了 SOCKS5 而没开 HTTP 代理，延迟读数可能不准
· 卸载：退出程序后把 ProxyPulse.app 拖进废纸篓即可，不写任何配置文件
